# Contract: Published scenario package (studio → website)

This is the contract between this feature and the public website (feature 001), as listed in FR-046 and FR-063.

- **Where it is written**: `content/scenarios/<slug>/v<N>/package.json`, next to small assets.
- **Large media**: kept in the data folder's `published-media/`, named by SHA-256 (research R19).
- **Versions**: a published version is never edited.
- **Self-contained**: the website MUST be able to build every page from the package alone (SC-015).

## Rules

- **Key numbers**: every key number states its `statistic` (`mean` or `p95`). Peaks are never included
  (Principle II).
- **Side by side**: visuals shown together share `colour_scale` and `deformation_scale`. A `magnification` other
  than 1 is shown on screen (Principle VII).
- **Interactive values**: every interactive value comes from `solved_cases`, by the stated `method`, and only
  inside the stated ranges.
- **Brand names**: none appear anywhere unless `brand_comparison` is filled in (FR-049).
- **Format changes**: changing this format means a new `format` version and a matching update to spec 001.
